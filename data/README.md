# Data

The NASA CMAPSS dataset files are not included in this repository.

Download them from the NASA Prognostics Data Repository:
https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/

After downloading, place the following files in this folder:

    data/raw/train_FD001.txt
    data/raw/test_FD001.txt
    data/raw/RUL_FD001.txt
